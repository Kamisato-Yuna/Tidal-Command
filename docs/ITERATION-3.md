# 第三次交互迭代：持续编辑与视角坐标

日期：2026-10-16。状态：实现及本地生产构建验收完成，发布流水线负责最终上线记录。

## 舰船编辑

- 放置后保持选中，舰旁仅显示旋转、移动两个图标；图标具备中文辅助标签与提示。
- 点击旋转图标或按R，围绕舰船起始格旋转。按住移动图标拖动，保留抓取偏移，不会把舰首瞬移到按钮所在位置；也可点击空海格移动。
- 合法舰队与暂放候选分离。无效候选保持为红色完整舰船及红色格位，不立即跳回；允许继续移动或旋转修正。出界舰船采用独立行列位置绘制，不把数字坐标溢出错误解释为下一行。
- 结束编辑按钮、Escape、切换其他舰船、点击编辑区外或失去窗口焦点时结束当前编辑。无效候选恢复上个合法舰位；从未合法放置的新舰移除。点击地图空格是移动操作，环绕拖动和点击编辑图标不是退出。
- 移动手柄拖动经过的中间位置不提交，合法释放才提交。因此无效拖动回退到拖动前的合法位置，不会落在途中经过的格子。
- 无效候选存在时开始战斗禁用。随机布阵/清空会确定地替换整份部署草稿。游戏存档只包含合法战斗舰队，没有写入暂放候选。
- 场景输入沿用最新已提交父组件状态桥接；部署动作还同步更新状态引用，避免同一指针事件的最终移动与释放读到过期候选。
- 真实浏览器发现并修复了快速切换舰船时上一艘舰的HTML移动按钮短暂拦截点击的问题：控件按舰船身份区分，并在主界面提交时同步位置和交互状态。拖动中的手柄不因位置变化重新挂载，保持指针捕获。原失败用例未在该点击前增加等待，最终构建已通过该快速生命周期回归。

## 坐标与镜头

默认镜头从逻辑A1原点一侧观察，A与1在同一角相接。逻辑格仍使用原有行列与世界位置，没有按镜头反转或重新编号。

水平环绕不再设角度限制。上下视角保留0.35–1.12弧度的安全俯视范围，避免翻到海面下。字母和数字保持屏幕正向，依据镜头位置分别切换到相应近侧边缘；跨边切换使用约0.22归一化分量的滞后区，避免边缘附近抖动。换边只改变标签锚点，不改变字母列、数字行或命中坐标。
